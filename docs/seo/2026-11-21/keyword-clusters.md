# Visa Prepper keyword clusters and target map

Date: 2026-11-21. Companion to `keyword-map.csv` in this folder, which has one row per keyword. Repo: production commit 99dac01 (clone on branch `seo/metadata-2026-11-21`). No repo source file was changed for this deliverable.

Owner constraints applied: no changes to visible page content and no design changes. Every action below is either (a) SEO metadata only (title tag, meta description, OG/Twitter, canonical, robots, sitemap, JSON-LD), (b) a NEW blog post in the existing MDX format, or (c) a refresh note for docs, with no edits to existing post bodies. Blog frontmatter `description` is shown on the page, so changing a post's meta description needs an SEO-only field. `seoTitle` already exists and only feeds `<title>`. Visa-type pages have separate `metaTitle`/`metaDescription` fields.

## At a glance

- **1001 keyword rows** in `keyword-map.csv`. They come from 2,508 input rows (kw-product, kw-routes, kw-markets, SERP-observed queries, blog primary keywords), normalized into 1,467 close-variant groups. 466 groups were excluded as out of scope (see Excluded keyword groups below). Merged variants are listed in each row's `notes`.
- **48 clusters**, each with exactly one primary target: 17 P1, 16 P2, 15 P3. Keyword rows: 44 P1, 627 P2, 330 P3.
- **12 rows have a search volume.** All come from Semrush, research date 2026-09-08, in the pk/in/bd databases (`docs/seo-keyword-map.md`). Every other volume is `unknown`. Volumes are never summed across variants or countries.
- **16 NEW blog posts proposed.** P1: the generic questions hub, the B1/B2 for parents post and the Philippines post. P2: Hindi/Urdu, F1 second attempt, spouse IR1/CR1, family immigrant visa, interview day, Pakistan visit visa, Nepal F1. P3 (optional or second wave): interview waiver, 221(g), visa bond, Ghana, Kenya, UAE residents.
- **Biggest single issue is the brand SERP, not content.** The homepage does not rank in the web results for `visaprepper` (gl=in/pk/ng, plus the lead's gl=us check on 2026-11-21); /partners, /contact, /terms or /features show instead. Fixing this takes homepage title and Organization/WebSite JSON-LD changes only.
- **Visa Prepper ranked in the top 10 for 0 of the 24 non-brand queries checked** (evidence/serp-observations.csv, 2026-11-21). Every existing post targeting those queries starts from outside the top 10.

## Methodology and data limits

- **No Google Search Console data.** Search Console is not connected in this session, so impressions, clicks, positions and indexed status are unknown. A `site:` query is not an index report.
- **No Keyword Planner and no paid keyword APIs** (no DataForSEO, no OpenSEO). The only volumes are Semrush Keyword Analytics rows with research date 2026-09-08 (pk/in/bd databases, snapshot date not returned), copied exactly from `docs/seo-keyword-map.md`. All other volumes are `unknown`. Close variants and country databases are never summed.
- **Autocomplete is not volume.** Google autocomplete (2026-11-21, `suggestqueries.google.com`, per-market `gl`) shows that a query exists, not how often it is searched. kw-product seeds were run in 10 markets, so a 10-market presence says little about demand. Autocomplete presence alone never makes a row P1.
- **Organic difficulty is a documented proxy, never an invented number.** In order of use: (1) Google SERP composition from `evidence/serp-observations.csv`, 31 SERPs captured 2026-11-21 in one desktop browser session, google.com, `hl=en`, `pws=0`, `gl` per market. The browser's IP country is unknown and may be South Asian, so `gl=us` results are approximate. Ranks count organic web results only. Some AI Overviews were still loading and were not captured. (2) The WebSearch (US index) qualitative ratings from `kw-routes.csv`, labelled as such. (3) The Semrush KD from 2026-09-08 where one exists, labelled as a third-party score, with KD 0 treated as uncertain. Google Ads competition was not used and is not organic difficulty.
- **Competing URLs** are up to 3 non-Visa Prepper results, by rank, from the matching SERP. When they come from a related query rather than the exact keyword, the row's `notes` say so, with the SERP query, market and date. Some URLs were truncated in the original capture and are reproduced as captured.
- **Dedupe rule.** Lowercase; U.S./USA/American normalized to 'us'; b1/b2, f-1, h-1b, ds-160, 214(b) and 221(g) spellings unified; plurals stemmed; stopwords dropped; year, 'sample/common/top', 'and answers', PDF and forum modifiers dropped; 'us' and 'visa' dropped when a U.S.-only visa token is present; word order ignored. The variant with the best evidence becomes the row: Semrush volume first, then an exact SERP observation, then seed status, then autocomplete reach, then shorter form. All other variants are listed in `notes`. Forum-only groups (only reddit/quora/facebook variants) were dropped.
- **One target per cluster.** Where the input files proposed different pages for the same keyword, the row's `notes` list the alternative and the cluster table records the cannibalization decision.
- **Product facts checked against the repo and the live app bundle** (`evidence/product-facts.md`, 2026-11-21): $44 one-time package = 6 AI video interviews + 10 document checks, valid 90 days; free plan = 1 document check and no interview; U.S. interviews in English, Urdu or Hindi; Bengali coming soon; UK/EU routes in English and limited to PK/IN applicants. Contradicted: the site invites Bangladeshi applicants to use U.S. routes, but the app blocks Bangladesh nationals.
- **Security.** This step used only local research files and the repo clone, with no new external fetches. The input files report that no fetched page or SERP contained instructions aimed at an AI agent. During the earlier SERP capture, evidence/competitors.md noted an unexpected travel.state.gov tab that appeared and closed in the browser pane; it was not interacted with.
